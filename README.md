# Retro Space — релизы

Описания сборок игры Retro Space по версиям.

Сами `.vpk` и PC-сборки в git не хранятся: GitHub не принимает файлы больше 100 МБ.
Артефакты публикуются в [GitHub Releases](https://github.com/NoLimits97/Retro_Space/releases), ссылка на конкретный релиз указывается в README каждой сборки.

## Как добавить новую версию

1. Создайте папку `versions/vita/<slug>` или `versions/pc/<slug>` и `README.md` по образцу существующих.
2. Заполните дату, имя артефакта и блок «Изменения».
3. Прикрепите `.vpk`/PC-сборку к GitHub Release и впишите ссылку в README.
4. Добавьте строку в таблицу выше и запись в `CHANGELOG.md`.
